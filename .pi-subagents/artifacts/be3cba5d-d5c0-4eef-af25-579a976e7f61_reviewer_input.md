# Task for reviewer

Read the current uncommitted scorecards/reports hardening diff and its changed/new tests. Do not edit anything. Build an evidence matrix mapping each claimed fix (identity/security, tenant invariants/RBAC, stale evaluation reconciliation/uniqueness, workspace sweep/snapshot consistency, report correctness, UI/accessibility) to exact test names/files. Identify missing or weak coverage, especially changes with no direct test. Distinguish unit/mock evidence from integration/database/browser evidence. Return concise findings with file paths and line numbers.

## Acceptance Contract
Acceptance level: reviewed
Completion is not accepted from prose alone. End with a structured acceptance report.

Criteria:
- criterion-1: Implement the requested change without widening scope
- criterion-2: Return evidence sufficient for an independent acceptance review

Required evidence: changed-files, tests-added, commands-run, validation-output, residual-risks, no-staged-files

Review gate: required by reviewer.

Finish with a fenced JSON block tagged `acceptance-report` in this shape:
Use empty arrays when no items apply; array fields contain strings unless object entries are shown.
```acceptance-report
{
  "criteriaSatisfied": [
    {
```
